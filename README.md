This repository contains a growing collection of shell scripts developed to automate repetitive infrastructure and system administration tasks.

## ⚙️ Automation Categories

### 🖥 Server Onboarding

Automates common tasks performed after deploying a new Linux server.

#### Typical Activities

- System updates
- Package installations
- User creation
- SSH configuration
- Standardized server setup
- Environment preparation

---

### 🔐 SSL Certificate Management

Scripts designed to simplify SSL certificate operations.

#### Features

- Copy certificates from remote systems
- Certificate backup procedures
- Certificate migration workflows
- Reduced manual certificate handling

---

### ☸️ Kubernetes Utilities

Tools and scripts that assist with Kubernetes administration.

#### Common Use Cases

- Cluster management
- Kubernetes troubleshooting
- Deployment assistance
- Operational automation
- Resource validation

---

### 📢 MOTD Configuration

Automates Message of the Day (MOTD) customization.

#### Benefits

- Standardized login banners
- Server identification
- Environment information display
- Administrative notices

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/iamraj-patel/shell-script.git
```

Move into the repository:

```bash
cd shell-script
```

Grant execute permissions:

```bash
chmod +x script.sh
```

Run:

```bash
./script.sh
```
